Requirements: Omarchy Quattro installation medium, plus an extra USB stick.
Super is ⌘.

1. Download wifi.sh onto the extra stick.
2. Super (⌘) + Shift + F (Files). Select the USB. Drag wifi.sh onto Home.
3. Super (⌘) + Return. Run:  sudo bash ~/wifi.sh
4. When it asks, plug in the Omarchy installer USB.
