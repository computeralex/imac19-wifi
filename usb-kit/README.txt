Keep this on your phone too. The iMac has no Wi-Fi yet.

On a Mac keyboard, Super is the Command key (next to the spacebar).

1. Plug in THIS stick (the one with imac19-wifi-install.sh at the top level).
2. Press Command + Return to open a terminal.
3. Type this and press Return:

   sudo bash $(find /run/media /media /mnt -name imac19-wifi-install.sh -print -quit)

4. Type the Omarchy password. Nothing will show. Press Return.
5. When it asks, unplug this stick if you need the port, plug in the
   Omarchy INSTALLER USB, press Return.
6. When it says done, press Return to shut down. Screen black, then power.
