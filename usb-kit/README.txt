Keep this where you can see it if you cannot memorize it. Super is the Command key.

1. Download the file. The browser will probably name it wifi.txt. That is fine.
2. On the iMac: Command + Shift + F (Files). Click the USB. Drag wifi.txt onto Home.
3. Command + Return. Type:  sudo bash ~/wifi.txt
4. Password (nothing shows). When it asks, plug in the Omarchy installer USB.
