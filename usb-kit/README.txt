Keep this where you can see it if you cannot memorize it. Super is ⌘.

1. Download wifi.sh onto a USB stick.
2. On the iMac: Super (⌘) + Shift + F (Files). Click the USB. Drag wifi.sh onto Home.
3. Super (⌘) + Return. Type:  sudo bash ~/wifi.sh
4. Password (nothing shows). When it asks, plug in the Omarchy installer USB.
